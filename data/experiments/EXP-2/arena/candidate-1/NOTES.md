## 바꾼 내용과 이유(원인별)

| 원인 | 바꾼 것 |
| --- | --- |
| 공통: 모델이 "원문 그대로"를 문장 뜻 수준으로 이해한다 | `## Quotes` 절을 새로 두고 검사 방식을 밝혔다: 프로그램이 공백만 무시하고 나머지 글자(마크다운 포함)를 대조한다. 규칙 3은 이 절을 가리킨다 |
| 마크다운 링크 벗기기 | 링크 없는 평문 문장을 먼저 고르게 했다. 링크가 든 구간이면 ``[`Name`](/path#anchor)``를 그대로 두고 `` `Name` ``로 줄이지 말라는 예를 넣었다 |
| 코드 펜스 첫 줄 줄이기 | 코드는 펜스 안쪽 줄만 인용하고 ```` ``` ```` 줄은 넣지 않게 했다. 여는 줄에 `theme={...}`가 붙는다고 이유를 적었다 |
| 표 행, 목록, 기호 다듬기(미확인 원인 후보) | 백틱, `**`, `\|`, 목록 기호, `—`(스냅샷에 166개), 굽은 따옴표를 유지하라고 적었다. NFKC는 이 기호들을 바꾸지 않는다 |
| 문장 고쳐 쓰기, 이어 붙이기, 생략(미확인 원인 후보) | 구간 이어 붙이기, 문구/대소문자/구두점 고치기를 금지했다(규칙 3의 생략 금지는 유지) |
| 마지막 확인 없음 | `{{documents}}` 뒤에 "각 인용을 위 페이지에서 찾아 글자 단위로 대조하라"는 한 줄을 붙였다. 문서가 길어 앞의 지시가 멀어지므로 출력 직전에 다시 보이게 했다 |

## 지킨 것

- 품질 규칙 파일(`quality/*.md`)과 규칙 8 문구는 손대지 않았다. `app/tests/test_quality.py`의 규칙 문구 검사(4개 형식, `{{` 없음, `only`/`always`/`never`/`longer`)를 후보 프롬프트 디렉토리로 FakeModel 렌더링해 통과를 확인했다. 모델 API는 부르지 않았다.
- 규칙 3의 "no added or removed markdown"을 남겼다. 대조군의 "Prefer one or two full sentences"는 `## Quotes` 첫 항목으로 옮겼다.
- 출력 스키마, 언어 규칙(문제 영어, 해설 한국어), 원문 인용 근거 규칙은 그대로다.
