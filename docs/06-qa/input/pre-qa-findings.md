## 쉬운 설명

웹 화면을 실제 사용자처럼 눌러 보면서 문제 풀이 흐름을 확인했다. 기본 흐름(세트 시작, 채점, 해설, 오답 태그, 이어 풀기, 복습)은 정상이었다. 결함은 3개를 찾았다.

1. **"새 세트 시작"을 두 번 빠르게 누르면** 서버 오류가 나거나 세트가 두 개 생긴다.
2. **화면이 지난 세트에 묶이면** 빠져나갈 버튼이 없다. 브라우저 저장소를 지워야 풀린다.
3. **정답이 거의 늘 A다.** 평가 대상 풀에서 코드 선택 문제 11개가 모두 A다. 보기를 섞지 않아 "늘 A"로 점수를 얻을 수 있다.

세 결함 모두 아직 고치지 않았다. 심각도는 06 계획에서 다시 정한다.

## 3. 발견

심각도는 05 계획 1.3 기준으로 붙인 잠정값이다.

### Q-1 "새 세트 시작" 두 번 누르기 (잠정 중간)

- **무엇이 일어나나**: `POST /api/sets`가 두 번 간다.
  - 두 번째 요청이 겹치면 500(`sqlite3.IntegrityError: UNIQUE constraint failed: quiz_sets.set_no`)이 나고, 화면에 `Error: 500 Internal Server Error`가 뜬다.
  - 겹치지 않으면 둘 다 성공해 세트가 두 개 생긴다. 화면은 먼저 끝난 응답의 세트를 붙든다(Q-2로 이어진다).
- **재현**: 세트를 끝낸 화면에서 브라우저 콘솔로 버튼을 같은 틱에 두 번 누른다.
  ```js
  const b = [...document.querySelectorAll('button')].find(x => x.textContent.includes('새 세트 시작')); b.click(); b.click()
  ```
  - 서버 로그: `POST /api/sets` 200 다음에 500.
  - 앞선 사례: 한 번의 조작 뒤 세트 4와 5가 함께 생겼다(`s004-dea231cf`, `s005-74ea96fd`).
- **원인 후보**: `web/src/App.tsx` `startSet`은 `disabled={busy}`로만 막는다. 다시 그리기 전에 들어온 두 번째 클릭은 막지 못한다. 서버 `POST /api/sets`에는 동시 요청 보호가 없다.
- **05와 관계**: 05 `findings.md` F-10(B-3, 세트 동시 생성 500)이 실제 화면 조작으로도 난다는 확인이다. F-10은 05에서 "기록만"이다.

### Q-2 지난 세트에 묶인 화면 (잠정 중간)

- **무엇이 일어나나**: 화면이 최신이 아닌 세트를 열고 있으면 답을 낼 때마다 `처리할 수 없다: set_closed`만 뜬다. "새 세트 시작" 버튼이 없다. 브라우저 저장소의 `agent-dev-quiz.set_id`를 지워야 풀린다.
- **재현**: Q-1로 세트 4, 5가 생긴 뒤 화면이 세트 4를 연 상태에서 답을 냈다. 서버 로그: `POST /api/sets/s004-dea231cf/answers` 409.
- **원인 후보**: `web/src/App.tsx` `recover()`가 `untagged_wrong`과 `already_answered`만 처리하고 `set_closed`는 처리하지 않는다.
- **다른 경로(미확인)**: 탭 두 개에서 각각 세트를 시작해도 같은 상태가 될 것으로 보인다.
- **05와 관계**: 새 발견. 05 F-9(오답 제출과 새 세트 동시 생성)와 같은 `set_closed` 계열이다.

### Q-3 정답 위치 쏠림 (잠정 중간, 높음 검토 필요)

- **무엇이 일어나나**: 선택형 정답이 A에 몰려 있다. 보기 순서를 섞지 않으므로 "늘 A"로 점수를 얻을 수 있다. 학습 결과와 오답 복습의 의미가 흐려진다.
- **수치**(`pool_snapshot_items`와 `questions.answer_key_json` 읽기 전용 집계):

  | 풀 | 단일 선택 | 복수 선택 | 코드 선택 |
  | --- | --- | --- | --- |
  | 평가 대상 `ps_326384fb5422`(`data/quiz.db`) | 18개 중 `A` 14, `B` 3, `C` 1 | 14개 중 13개가 `A` 포함(`A,C` 8, `A,B` 3, `A,D` 2, `B,E` 1) | 11개 모두 `A` |
  | scratch `ps_5409d7629f71` | 14개 중 `A` 11, `B` 3 | 13개 모두 `A` 포함(`A,C` 6, `A,B` 5, `A,D` 2) | 13개 중 `A` 11, `C` 2 |

- **원인 후보**: 생성 프롬프트(`packs/langchain/prompts/generate.md`)가 정답 위치를 정하지 않는다. Judge `no_cue` 항목은 문제 하나씩만 보므로 풀 전체의 쏠림은 못 잡는다. 서버와 화면은 저장된 순서 그대로 보기를 낸다.
- **고치는 방향(미정)**: 출제 때 보기를 섞어 저장하기, 또는 세트를 낼 때 섞고 채점 키를 바꾸기. 후자는 `server.py`, 채점, 화면, 세트 기록을 함께 바꾼다.
- **05와 관계**: 새 발견. 05 F-1~F-19에 없다.
