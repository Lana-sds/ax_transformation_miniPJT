## 쉬운 설명

설계 때 약속한 수용 기준 9개와 MVP 완료 조건 4개를 하나씩 증거와 맞췄다. 테스트만 믿지 않았다. 앱 코드를 쓰지 않는 별도 스크립트로 DB 값을 다시 계산했고, 코드를 보지 않은 검토자가 요구사항만 보고 만든 사례 40개를 실제 API에 돌렸다. 평가 도구(ouroboros)는 9개 모두 통과로 판정했다. 지금 데이터는 기준을 모두 채운다. 다만 일부러 깨 보기에서, 같은 기준을 나중에 깨뜨릴 수 있는 경로가 나왔다. 그 경로는 "보장" 열과 [findings.md](findings.md)에 적는다.
