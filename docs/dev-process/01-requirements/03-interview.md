### 종료 점검

| 회차 | closer | contrarian | gap_hunter | 처리 |
| --- | --- | --- | --- | --- |
| 1차 | seed_ready | high | high | 서버 완료 신호를 받아들이지 않고 빈칸 초안을 사용자에게 확인 |
| 2차 | seed_ready | medium | medium | 통과. medium 항목은 2단계 미결로 넘김 |

1차 점검 후 사용자가 승인한 결정:

- 채점: 단일·복수·코드 선택은 정답 키 정확 일치(복수 선택 부분 점수 없음). 단답은 생성 시 허용 답안 목록을 만들고 Judge가 검증, 채점은 대소문자·공백 정규화 후 목록 일치. 풀이 시점 LLM 채점 없음
- 오답 태그: 사용자가 오답 화면에서 독해 실수/개념 실수를 고르고, 독해 실수면 헷갈린 영어 구절도 고른다. 자동 태그 없음
- 풀 소진: 6세트 후에는 복습 문제와 이미 맞힌 문제를 다시 낸다. 추가 배치는 수동 명령으로 생성
- 세트 구성: 새 문제 7개 이상(주제·형식 무작위), 복습 최대 3개
- 마감 대비 축소 순서: 11/5 저녁까지 통과 30개 미만이면 ① 변형 문제 생성 제외 ② Langfuse 내보내기 제외 ③ 풀 목표 30개(주제별 5개)로 낮추고 사용자 면제 기록. React UI는 유지

### 목표 재진술 (사용자 승인)

> LangChain·LangGraph로 LLM 앱을 만드는 한국인 개발자(본인)가, 공식 문서 원문 인용으로 검증된 영어 예상 문제(day2~day7, 4개 형식)를 10문제 세트 단위로 원할 때마다 풀고, 영·한 구절 매핑 해설과 독해 실수/개념 실수 태그에 따른 복습까지 이어가는 로컬 웹앱(FastAPI + SQLite + React, Bedrock 모델 호출)을 2026-11-07까지 완성한다. 완료 기준은 검증 통과 문제 60개, 본인 20문항 감사 통과, 3세트 풀이다.
