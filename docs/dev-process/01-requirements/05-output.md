## A.3 일정과 축소 기준

- 마감: 2026-11-07(AX 미니과제 마감). 요구사항 정의서 C-1.
- 축소 기준: 2026-11-05 저녁까지 통과 문제가 30개 미만이면 아래 순서로 줄인다. React UI는 유지한다.
  1. 변형 문제 생성을 뺀다(FR-6).
  2. Langfuse 내보내기를 뺀다(NFR-5.2).
  3. 풀 목표를 30개(버킷당 5개)로 낮추고 사용자 면제로 기록한다.
- 요구사항 정의서의 우선순위 "축소 대상"은 1, 2번에 해당하는 요구사항이다.
- Seed의 `scope_cut_waiver` 종료 조건이 이 기준을 따른다.

## A.4 2단계로 넘긴 미결 사항

1단계 끝에 열려 있던 11개 항목이다. 2단계 처리 결과는 [01-open-items.md](../02-spec-design/01-open-items.md)와 [design.md](../../02-spec-design/output/design.md) 9장에 있다.

| 항목 | 내용 |
| --- | --- |
| 페이지 허용 목록 | 주제별 공식 문서 페이지 목록을 docs MCP로 작성 |
| "통과" 상태 정의 | 게이트 + Judge 통과. 감사는 표본에만 적용한다는 정의를 확정 |
| 인용 비교 정규화 | 공백, 마크다운, 코드 블록 처리 규칙 |
| 감사 무작위 시드 | 재현 가능한 표본 추출 방법 |
| 단답 허용 답안 범위 | 동의어 누락 위험 |

| Bedrock 운영 | 재시도, 요청 제한 처리, 비용 상한 |
| React-FastAPI 연결 | CORS. 이후 배포 시 인증 |
| 유사 중복 문제 | 검출 방법 |
| SQLite 운영 | 스키마 변경과 백업 |
| 생성 시간 | 문제 1개당 생성 시간 측정. 3일 일정에 스펙, 파이프라인, 서버, UI, 허용 목록, 60문제, 감사, 3세트가 모두 들어 있다 |
