## 결정

| 결정 | 내용 | 바뀐 기존 결정 |
| --- | --- | --- |
| `audit_id` 형식 | `"au_" + pool_snapshot_id`의 해시 부분(`ps_` 뒤 12자). 스냅샷당 감사 하나라 결정적이다 | 없음. design.md 5.2에 규칙이 없다 |
| 표본보다 작은 풀 | 풀 스냅샷이 20문항 미만이면 `POST /api/audits`가 409 `pool_too_small`. 풀이 없으면 409 `no_pool`. 아무것도 저장하지 않는다 | 없음. D-h의 기존 이유 값을 쓴다 |
| 다시 기록 | 같은 문항을 다시 저장하면 행을 바꾸고 `result`를 다시 계산한다. 표본 밖 문항은 400, 없는 감사는 404 | 없음 |
| 현재 감사 없음 | `GET /api/audits/current`는 현재 풀 스냅샷의 감사가 없으면 404 | 없음 |
| `audit_failed` 전환 | T5.2는 `result`만 계산한다. 실패 문제의 상태 전환과 재감사는 T5.6에서 한다 | 없음 |
