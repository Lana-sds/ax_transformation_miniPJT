--- stdout ---
<원문>`이다. `sed -n 'a,bp'`, `wc -l`, `sha256sum`이 된다. `tail -c +N`은 기대대로 동작하지 않았다(`wc -c`가 31,300을 냈다).

- 결과: `graph-api.mdx` 31,352B, sha256 서버와 일치.
- Git Bash가 `/oss/...` 인자를 `C:/Program Files/Git/oss/...`로 바꿔 첫 실행이 실패했다. `MSYS_NO_PATHCONV=1`로 해결했다.
